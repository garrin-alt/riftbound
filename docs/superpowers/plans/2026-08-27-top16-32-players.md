# GNL Top 16 → 32 Players Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the GNL Top 16 tool run a 32-player edition (8 groups → Top 16 playoff) while
keeping the existing 16-player edition (4 groups → Top 8 playoff) working exactly as it does
today, selectable at setup.

**Architecture:** Replace the tool's two hardcoded arrays (`GROUPS`, `PLAYOFFS`) with one
function, `t16BuildBracket(groupCount)`, generated from a "primary/mirror stream" model that
reproduces today's 4-group bracket exactly and extends cleanly to 8 groups. Task 1 rewires every
function that consumed the old constants onto the generalized equivalents while the tool still
only ever runs in 16-player mode (groupCount hardcoded to 4 at setup) — a behavior-preserving
refactor, verified byte-identical to today. Task 2 adds the one remaining piece: a 16/32 toggle
on the setup screen that lets `groupCount` actually become 8.

**Tech Stack:** Vanilla ES5 JS inside an IIFE in `index.html` (`// ==================== GNL TOP 16
====================`), no build step, no framework.

**Spec:** `docs/superpowers/specs/2026-08-27-top16-32-players-design.md`

## Global Constraints

- `groupCount` is either `4` (16 players) or `8` (32 players) — no other values.
- A tournament saved before this change has no `groupCount` key on `t16State`; every function
  that reads it must fall back to `4`, reproducing today's exact behavior with zero migration.
- The 16-player mode's match keys, labels, and "waiting on" hint text must be byte-identical to
  today's hardcoded `PLAYOFFS` array — this is a behavior-preserving refactor for that mode, not
  a redesign.
- The bracket's actual invariant (verified against the real existing code, not the first draft of
  the design doc): a group's two qualifiers are split into two independent bracket streams
  (primary/mirror) from round one, so they can only meet in the Grand Final — never one round
  earlier.
- This tool's playoff bracket stays single-elimination throughout at every size — no
  double-elimination behavior (that belongs to the separate new bracket tool, out of scope here).
- No committed automated test suite exists in this repo (per `CLAUDE.md`); verification is manual,
  driven through the actual browser UI.
- **Every task must leave the tool fully working end-to-end** — no task may leave a dangling
  reference to a removed identifier for a later task to fix. Concretely: nothing may still
  reference `GROUPS` or `PLAYOFFS` after Task 1 lands, because Task 1 removes them.

- **This task deliberately does not add the 16/32 toggle.** `t16RenderSetup` in this task always
  builds a `groupCount:4` tournament — identical to today's only option. The toggle is Task 2's

  var GROUP_MATCHES = [
    { k:'m1', label:'Match 1' },
    { k:'m2', label:'Match 2' },
    { k:'w',  label:'Winners Match' },
    { k:'l',  label:'Losers Match' },

  // Letters A, B, C... for however many groups this tournament uses (4 or 8).
  function t16GroupLetters(groupCount){
    var letters = [];
    for(var i=0;i<groupCount;i++) letters.push(String.fromCharCode(65+i));
    return letters;
  }
  // Groups for the ACTIVE tournament — falls back to 4 before a tournament exists, or for any
  // tournament saved before groupCount existed, matching the tool's original only-ever-4 behavior.
  function t16ActiveGroups(){
    return t16GroupLetters((t16State && t16State.groupCount) || 4);
  }

  // Assigns key/label/srcLabel to every match in one already-built round. keyPrefix is 'qf',
  // 'sf', 'r16-' or 'f'; a single-match round gets the bare prefix as its key (e.g. 'f'),
  // multi-match rounds get prefix+1-based-index (e.g. 'qf1', 'r16-3').
  function t16LabelRound(round, keyPrefix, labelFn){
    round.forEach(function(m, i){
      m.key = round.length === 1 ? keyPrefix : (keyPrefix + (i + 1));
      m.label = labelFn(i);
    });
    round.forEach(function(m){
      m.srcLabel = [m.srcA, m.srcB].map(function(src){
        if(src.group != null) return (src.seed === 0 ? '1st' : '2nd') + ' Group ' + src.group;
        return 'Winner ' + src.key.toUpperCase();
      });
    });
    return round;
  }

  // The playoff bracket for a given group count (4 or 8), as an array of rounds; each round is
  // an array of match defs { key, label, srcA, srcB, srcLabel }. src.group/seed points at a
  // group-stage result (seed 0 = 1st place, seed 1 = 2nd place); src.key points at an earlier
  // playoff match's winner.
  //
  // Two independent "streams" run through the whole bracket — primary and mirror. For each
  // group pair (X,Y) taken two letters at a time: the primary stream's first match is
  // 1st(X) v 2nd(Y); the mirror stream's is 1st(Y) v 2nd(X). Each stream is single-eliminated
  // entirely on its own; the two streams' champions meet ONLY in the Grand Final — a group's own
  // two qualifiers always land one in each stream, so they can never face each other before the
  // Final. For podCount:2 (groupCount:4) this reproduces the tool's original hardcoded PLAYOFFS
  // array exactly, key-for-key and label-for-label — verified during design. podCount:4
  // (groupCount:8) adds one earlier round (r16-1..r16-8) ahead of the same qf/sf/f shape.
  function t16BuildBracket(groupCount){
    var letters = t16GroupLetters(groupCount);
    var podCount = groupCount / 2; // 2 for groupCount:4, 4 for groupCount:8
    var pods = [];
    for(var p=0;p<podCount;p++) pods.push({ gx:letters[p*2], gy:letters[p*2+1] });

    function podMatch(pod, mirrored){
      var hi = mirrored ? pod.gy : pod.gx, lo = mirrored ? pod.gx : pod.gy;
      return { srcA:{group:hi, seed:0}, srcB:{group:lo, seed:1} };
    }

    if(podCount === 2){
      var qf = [ podMatch(pods[0], false), podMatch(pods[1], false),
                 podMatch(pods[0], true),  podMatch(pods[1], true) ];
      var sf = [ { srcA:{key:'qf1'}, srcB:{key:'qf2'} },
                 { srcA:{key:'qf3'}, srcB:{key:'qf4'} } ];
      var f  = [ { srcA:{key:'sf1'}, srcB:{key:'sf2'} } ];
      return [
        t16LabelRound(qf, 'qf', function(i){ return 'QF'+(i+1); }),
        t16LabelRound(sf, 'sf', function(i){ return 'Semifinal '+(i+1); }),
        t16LabelRound(f,  'f',  function(){ return 'Grand Final'; })
      ];
    }

    var r16 = [ podMatch(pods[0], false), podMatch(pods[1], false), podMatch(pods[2], false), podMatch(pods[3], false),
                podMatch(pods[0], true),  podMatch(pods[1], true),  podMatch(pods[2], true),  podMatch(pods[3], true) ];
    var qf2 = [ { srcA:{key:'r16-1'}, srcB:{key:'r16-2'} }, { srcA:{key:'r16-3'}, srcB:{key:'r16-4'} },
                { srcA:{key:'r16-5'}, srcB:{key:'r16-6'} }, { srcA:{key:'r16-7'}, srcB:{key:'r16-8'} } ];
    var sf2 = [ { srcA:{key:'qf1'}, srcB:{key:'qf2'} }, { srcA:{key:'qf3'}, srcB:{key:'qf4'} } ];
    var f2  = [ { srcA:{key:'sf1'}, srcB:{key:'sf2'} } ];
    return [
      t16LabelRound(r16, 'r16-', function(i){ return 'R16 Match '+(i+1); }),
      t16LabelRound(qf2, 'qf',  function(i){ return 'QF'+(i+1); }),
      t16LabelRound(sf2, 'sf',  function(i){ return 'Semifinal '+(i+1); }),
      t16LabelRound(f2,  'f',   function(){ return 'Grand Final'; })
    ];
  }
  // Bracket for the ACTIVE tournament (same fallback rule as t16ActiveGroups).
  function t16ActiveBracket(){
    return t16BuildBracket((t16State && t16State.groupCount) || 4);
  }
  // Find one match's def anywhere in a bracket, by key.
  function t16MatchDef(key, bracket){
    for(var r=0;r<bracket.length;r++)
      for(var m=0;m<bracket[r].length;m++)
        if(bracket[r][m].key === key) return bracket[r][m];
    return null;
  }

  // Editing a match invalidates everything that fed off its result — built from the same
  // bracket structure t16Players/t16WhatsAppText use, so it can never drift out of sync with them.
  function t16Downstream(key){
    var m = key.match(/^([A-H])-(m1|m2|w|l|d)$/);
    var bracket = t16ActiveBracket();
    if(m){
      var g = m[1];
      var chain = { m1:['w','l','d'], m2:['w','l','d'], w:['d'], l:['d'], d:[] }[m[2]]
        .map(function(k){ return g+'-'+k; });
      var allPlayoffKeys = [];
      bracket.forEach(function(round){ round.forEach(function(mm){ allPlayoffKeys.push(mm.key); }); });
      return chain.concat(allPlayoffKeys);
    }
    // Reverse-dependency map: key -> keys that directly reference it as a source.
    var dependents = {};
    bracket.forEach(function(round){
      round.forEach(function(mm){
        [mm.srcA, mm.srcB].forEach(function(src){
          if(src.key != null) (dependents[src.key] = dependents[src.key] || []).push(mm.key);
        });
      });
    });
    var downstream = [], seen = {}, queue = (dependents[key] || []).slice();
    while(queue.length){
      var k = queue.shift();
      if(seen[k]) continue;
      seen[k] = true;
      downstream.push(k);
      (dependents[k] || []).forEach(function(k2){ queue.push(k2); });
    }
    return downstream;
  }
